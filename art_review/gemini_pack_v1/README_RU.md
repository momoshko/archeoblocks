# Арт через Gemini (Nano Banana Pro) — инструкция

Пакет заменяет задание для Codex (`codex_pack_v3`) и рассчитан на Gemini.
Главное — **21 находка** (картинки для коллекции, окна победы и фрагментов на поле).
Дальше по желанию: фон и эмблема меню, иконка и обложка для Яндекса, иконки кнопок, эффекты.

Все промпты по порядку — в [PROMPTS_RU.md](PROMPTS_RU.md). Те же данные для скрипта — в `prompts.json`.

## Что понадобится

- **Модель: Nano Banana Pro (Gemini 3 Pro Image).**
  - Удобнее всего **Google AI Studio** (aistudio.google.com), модель `gemini-3-pro-image`.
    Там можно выбрать формат 1:1 и разрешение 2K, и на картинках нет видимого значка-звёздочки.
  - Можно и в **приложении Gemini** («Создать изображение», модель Pro). На бесплатном тарифе
    и тарифе Pro в углу бывает видимый значок-звёздочка. Скрипт убирает его, если он
    стоит отдельно от предмета, но лучше, чтобы его не было.
  - Невидимая метка SynthID есть на всех картинках Gemini. Она не мешает игре.
- **Картинки-образцы** из папки `references/` (их нужно прикладывать к запросу):

| Файл | Для чего |
| --- | --- |
| `golden_mask_on_white.png`, `courtyard_seal_on_white.png`, `stone_amulet_on_white.png` | утверждённый стиль находок — прикладывать ко всем находкам, эмблеме, иконке и эффектам |
| `screen_menu.png`, `screen_game.png` | как выглядит игра — для фона меню и обложки |
| `buttons_on_white.png` | кнопки игры — для иконок на кнопки |

## Почему две картинки на один предмет

Gemini не умеет рисовать прозрачный фон. Поэтому каждый предмет делаем два раза:
сначала **на белом фоне**, потом просим **ту же картинку на чёрном**.
Скрипт сравнивает их и получает честную прозрачность, даже на мягких краях и бликах.
Если чёрная версия вышла с изменённым предметом, скрипт возьмёт только белую
и вырежет белый фон — тоже годится, края будут чуть грубее.

Фон меню, иконку и обложку для Яндекса делать по одному разу: они без прозрачности.

## Одна находка — по шагам

1. Откройте новый чат (удобно по одному чату на главу, так стиль держится ровнее).
2. Приложите три образца находок из `references/`.
3. Вставьте промпт этой находки из `PROMPTS_RU.md` (весь блок в рамке, по-английски).
   Формат 1:1, разрешение 2K, если есть выбор.
4. Если не нравится — попросите поправить словами: «толще контур», «меньше мелких деталей»,
   «теплее цвет», «предмет крупнее в кадре». Нужно, чтобы:
   - предмет был целиком в кадре, с пустыми полями вокруг;
   - свет падал сверху слева, как на образцах;
   - не было текста, букв, рамки, подставки и тени на фоне;
   - силуэт читался, если картинку сильно уменьшить.
5. Сохраните картинку как `raw/<id>_white.png` (например `raw/bronze_key_white.png`).
6. В том же чате отправьте «второй проход» (текст в начале `PROMPTS_RU.md`) и сохраните
   ответ как `raw/<id>_black.png`.

Фрагменты рисовать **не нужно**: скрипт сам разрежет находку на 2–3 части по неровным
краям, каждая часть остаётся на своём месте, как у золотой маски.

Для фона меню, иконки и обложки сохраняйте один файл: `raw/background_image.png`,
`raw/store_icon_image.png`, `raw/store_cover_image.png`.

## Что дальше

Проще всего: **положите файлы в `art_review/gemini_pack_v1/raw/` и напишите мне.**
Я прогоню скрипт, проверю листы, подключу находки к экспедициям (коллекция, окно победы,
фрагменты на поле), сниму скриншоты RU/EN и запишу источник в `CREDITS.md`.

Можно и самим (нужен Python 3):

```
pip install pillow numpy
python tools/gemini_import.py --check        # чего ещё не хватает
python tools/gemini_import.py                # обработать всё, что есть в raw/
python tools/gemini_import.py bronze_key     # только одну
```

Скрипт кладёт готовые файлы сразу по местам (`assets/artifacts/<глава>/...`)
и делает листы для проверки в `review/`: каждая картинка на тёмном и на светлом фоне.

## С чего начать

Сначала **три находки на пробу**, по одной из каждой главы: `bronze_key` (1 часть),
`priest_seal` (2 части), `emerald_idol` (3 части). Я подключу их и покажу в игре.
Если стиль совпадает с золотой маской — делаем остальные 18.
