# Арт для Gemini, пакет v2 — как пользоваться

Главный файл — **`GEMINI_BRIEF.md`**. В нём правила для Gemini, стиль и все 50 спрайтов
по номерам. Его нужно один раз дать Gemini, дальше вы пишете только номер.

Иконки и эффекты быстрее делать **листами** — по 4–8 штук на одной картинке:
файл **`GEMINI_SHEETS.md`** (раздел «Листы» ниже).

## Что в пакете (50 штук)

| № | Что | Зачем |
| --- | --- | --- |
| 1–18 | Оставшиеся находки (3 уже готовы: ключ, печать, идол) | Коллекция, окно победы, фрагменты на поле, реставрация |
| 19–22 | Фон меню и три фона глав | Сейчас везде один фон, нарисованный кодом (кирпичная стена). Фоны глав подойдут и для слоёв бесконечного режима |
| 23 | Эмблема | Сейчас нарисована кодом |
| 24–26 | Иконка, обложка, широкий баннер для Яндекса | Иконка и обложка сильнее всего влияют на клики в каталоге |
| 27–41 | Иконки для кнопок (пауза, назад, в меню, заново, отмена, подсказка, настройки, звук, музыка, играть, закрыть, бесконечный режим, кисть, губка) | Сейчас кнопки только с текстом; иконки делают интерфейс «дороже» и понятнее |
| 42–46 | Эффекты: пыль, искра, блик, осколок камня, сияние находки | «Сочность» линий, раскопки и находки |
| 47 | Бесшовная текстура земли | Реставрация: вместо нарисованной шейдером |
| 48–50 | Картинки глав | Карточки глав в выборе экспедиций |

Панели, кнопки-подложки, блоки, клетки, камни и корни уже есть и выглядят цельно —
их не переделываем.

## Вариант 1: Gem (удобнее для многих сессий)

1. Gemini → **Gems** → создать новый, имя «Археоблоки — художник».
2. Инструкции: `Следуй файлу GEMINI_BRIEF.md из знаний. Отвечай по-русски коротко.`
3. Знания: добавить `GEMINI_BRIEF.md` и картинки из `references/`.
4. Инструмент по умолчанию — «Создать изображение», модель — Pro (Nano Banana Pro).
5. Открыть Gem и писать номера.

## Вариант 2: обычный чат

1. Новый чат, модель Pro (Nano Banana Pro).
2. Прикрепить `GEMINI_BRIEF.md` и картинки из `references/`, написать «Начинаем».
3. Писать номера. Если Gemini начал «забывать» стиль — новый чат, снова файл и образцы.

## Команды

| Пишете | Что будет |
| --- | --- |
| `7` или `stone_charm` | Нарисует №7 |
| `ч` | Та же картинка на чёрном фоне (для находок, иконок, эффектов) |
| `далее` | Следующий номер |
| `ещё` | Другой вариант того же |
| `список` | Все номера |
| любой текст | Правка последней картинки («крупнее», «меньше деталей», «теплее») |

## Сохранение

- Находки, эмблема, иконки, эффекты: `<id>_white.png` и `<id>_black.png`.
- Фоны, витрина, текстура, картинки глав: `<id>_image.png`.
- Всё — в `art_review/gemini_pack_v2/raw/`. Потом напишите Claude: он обработает
  (`tools/gemini_import.py`), подключит в игру и снимет скриншоты.

Claude сам разрежет лист: найдёт каждую картинку по пустому месту вокруг и разложит по порядку
(слева направо, сверху вниз). Важно, чтобы картинки не касались друг друга и на листе не было
подписей и линий сетки. Если одна иконка не удалась — её можно переделать отдельно по номеру
из `GEMINI_BRIEF.md` (например, `31`), отдельный файл главнее листа.

## Что уже готово и что дальше

**Порядок генерации (2026-10-04, по важности):**

1. `Л5` — иконки «Экспедиции» и «Коллекция» для главного меню (сейчас у этих кнопок иконок нет).
2. `24`, `25`, `26` — иконка, обложка и баннер Яндекса (без них не выпустить игру).
3. `Л8` — осколки самоцветов и конфетти (самая заметная «сочность» при сборе линии и в победе).
4. `Л9` — лента и звёзды для окна победы.
5. `48`–`50` — картинки глав; `Л7` — свет для победы и серий.
6. `Л6` — рука для обучения, язык, серия.
7. `51`–`53` — фоны коллекции, реставрации и глубины; `47` — текстура земли.

Правило для листов: **без подписей под картинками** и **чистый чёрный фон** во втором проходе
(в Л1 и Л4 Gemini подписал спрайты и сделал фон серым — скрипт справился, но лучше без этого).

- **Готово (1–23):** все находки, фон меню, три фона глав, эмблема — уже в игре.
- **Готово (листы Л1–Л4):** иконки на кнопках и эффекты (пыль, осколки, искры, сияние, блик) — уже в игре.
  Gemini подписал картинки и сделал «чёрный» фон серым — скрипт это теперь сам исправляет.
- **Дальше:** 24–26 (иконка, обложка и баннер для Яндекса), потом 47 (текстура земли) и 48–50 (картинки глав).

Фоны глав игра берёт из главы (`background_texture` в `resources/chapters/*.tres`),
в бесконечном режиме фон меняется со слоем глубины. Иконки и эффекты скрипт
положит в `assets/ui_art/icons` и `assets/ui_art/fx`, а в сцены их встроит Claude
отдельным шагом.
