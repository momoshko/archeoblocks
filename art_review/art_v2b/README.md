# Archeoblocks · ART V2B

**Production-candidate для review перед первой интеграцией в Godot.** Созданы 16 production PNG, 5 обязательных review PNG и дополнительный лист проверки alpha. Статические проверки пройдены; пользовательское утверждение пакета ещё не подразумевается.

Generated with the available built-in ImageGen; exact underlying image model/quality tier was not exposed by the tool.

## Визуальное направление

Утверждённый **Light Sandstone Courtyard**: светлый тёплый песчаник, мягкая фаска, слегка срезанные углы и умеренные сколы по краям. Центральные поверхности оставлены свободными для текста. Зелёный камень выделяет основные действия; светлый песчаник служит secondary, серо-бежевый — disabled. Золото используется только для выделения и найденных артефактов.

Референсы: `art_review/art_v1/master_menu.png`, `master_gameplay.png` и `art_review/art_v2a/gameplay_material_sheet.png`. Одна sandstone anchor-панель → родственные headers/frame/popup/button/slot; состояния кнопок и карточек получены последовательными edit-вызовами. 16 успешных вызовов встроенного ImageGen, по одному на каждый production asset. Полные неизменённые результаты — `sources/`; точные фактически отправленные запросы и входные изображения — [prompts.json](prompts.json).

## Геометрия и обработка

- Все элементы центрированы на canvas. Состояния primary/secondary/disabled имеют **побайтно одинаковую alpha**. То же для open/locked/completed и known/unknown. Общий crop задаётся мастером соответствующего семейства.
- Пять исходников содержали готовую alpha; она сохранена в мастерах с удалением отдельных оторванных пикселей. У остальных 11 RGB-исходников удалена нейтральная нарисованная подложка, в том числе внутри board frame и selected. Внешний край маски сокращён на один исходный пиксель для устранения светлой каймы. Для состояний используется общая мастер-маска.
- Изменение пропорций выполнено методом девяти областей: углы масштабируются равномерно, стороны — по своей оси, центральная поверхность заполняет оставшееся место. Материал не заменялся процедурным рисунком. Для более спокойной board frame масштаб углов и толщины относительно обычного уменьшения — 0.70.
- Дополнительная цветокоррекция не применялась. Исходные RGB/alpha и все prompts сохранены. Полные параметры: [export_report.json](export_report.json), [export_pack.cjs](export_pack.cjs).
- Board frame: гарантированно прозрачный квадрат под grid — **(131,131,762,762)** на canvas 1024×1024. В gameplay-review рамка 672×672; поле 496×496, шаг клетки **62 px**, ни один угол клетки не закрыт рамкой.

## Заметки для будущей интеграции в Godot

1. Persistent UI остаётся настоящими узлами сцены. Текст — отдельные Label, интерактивность — реальные кнопки; эти PNG задают только оформление.
2. Рамку поля масштабировать равномерно; grid совмещать с `boardGridSafeRect`. Внутри прозрачного отверстия нужна спокойная тёмная подложка под V2A-материалами.
3. Панели и кнопки проверять как NinePatchRect или соответствующее оформление кнопки. Исходные поля `ninePatchMargins` заданы в пикселях PNG и включают прозрачные поля. Их нельзя переносить как независимые от масштаба screen-pixel значения. Работу девяти областей здесь проверяет только offline compositor.
4. Для состояний использовать одинаковые размер, позицию и pivot. Selected накладывать на тот же canvas кнопки. Это узкий контур, а не отдельная большая панель.
5. Текст/иконки держать в `textSafeRect`; для кириллицы использовать отдельный подходящий шрифт. В review: кремовый текст на primary, тёмно-коричневый на sandstone. Production PNG не содержат надписей.
6. У стандартной кнопки непрозрачная высота составляет 144 из 192 px: canvas 256×64 даёт тело 240×48; canvas около340×85 — тело около319×64. Не путать прозрачное поле текстуры с целевой областью нажатия. Компактная кнопка в review имеет тело около48 px.
7. Материальные состояния карточек дополнять отдельными понятными подписями/значками. Голосовая доступность, focus/hover/pressed и фактическая блокировка действий относятся к интеграции; этот пакет не меняет UX или gameplay.
8. `.gdignore` в обоих каталогах намеренно предотвращает импорт на этом этапе. Снимать его с production-каталога только в рамках согласованной интеграции; review-материалы не нужны в runtime.

## Проверка и ограничения

**99/99 технических проверок пройдены.** Primary/disabled/secondary различимы в grayscale: средняя яркость чистой области 90.07 / 158.76 / 213.59. Средний контраст выбранного текста относительно поверхности primary — 6.30:1, secondary — 9.37:1. Это поддерживающие метрики, а не полная сертификация доступности.

Визуально проверены все пять обязательных листов и alpha-аудит: единое семейство, чистые текстовые области, прозрачные центры, читаемые состояния, спокойная рамка и сохранение приоритета V2A-блоков. [VERIFICATION.md](VERIFICATION.md) и [verification.json](verification.json) содержат результаты.

Остаётся проверить на устройствах фильтрацию, фактические размеры Control, масштабирование NinePatch, шрифты и интерактивные состояния. Это production-candidate, готовый к утверждению визуального пакета; runtime-интеграция ещё не выполнена. Gameplay-код, сцены, темы и настройки проекта не менялись. Все 22 файла, перечисленные в принятом manifest V2A, сохранили хеши.

## Повторная сборка

Из корня репозитория:

```powershell
node art_review/art_v2b/export_pack.cjs
node art_review/art_v2b/build_reviews.cjs
node art_review/art_v2b/verify_pack.cjs
```

Скрипты используют доступный на этой машине Node.js/Sharp по абсолютному пути. На другой машине заменить путь `require` на установленный `sharp`. Сборка читает сохранённые `sources/` и не вызывает ImageGen повторно. Запись ограничена каталогами ART V2B. SVG используется только для отдельных review-текстов и простой подложки; production-фактуры получены через ImageGen.
